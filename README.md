# Omnia Nabil — Android Developer Portfolio

A modern Next.js + TypeScript portfolio starter tailored to Omnia's Android Developer profile.

## Run locally
1. Install Node.js 20+.
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000

## Before publishing
- Replace placeholder project mockups with approved screenshots.
- Add the final CV PDF under `public/` and connect the Download CV button.
- Review the exact wording of the SHIFT contribution against company confidentiality rules.
- Add GitHub repository links for projects where the exact repository is known.

## Deploy
Push the folder to GitHub and import the repository into Vercel.
